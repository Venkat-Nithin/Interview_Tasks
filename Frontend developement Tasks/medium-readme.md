# React Frontend Interview Exercise - Medium Level

## Overview

This package contains two exercises to evaluate your React development skills at an intermediate level:
- Task A: Code Review and Performance Optimization
- Task B: Implementation Exercise

**Skills Evaluated:**
- React best practices
- Performance optimization
- State management
- API integration
- Component architecture
- Error handling

**Time Allocation:** 3 hours total (recommended: 1.5 hours for Task A, 1.5 hours for Task B)

## Instructions

### Task A: Code Review and Performance Optimization

Review the `ProductPage.jsx` component, which implements a product listing page with filtering and cart functionality. While it works correctly, there are several performance and structural issues.

**Your Task:**
- Identify at least 5 opportunities for optimization and improvement
- Focus on:
  - Performance optimization
  - Code structure and organization
  - React best practices
  - State management
- Document your findings and proposed changes in the `optimization-review.md` file
- Explain why each change would improve the component

### Task B: Implementation Exercise

Implement a "Data Dashboard" component based on the requirements in the starter files.

**Requirements:**
1. Fetch data from the provided mock API endpoint
2. Create a dashboard that displays:
   - A line chart showing data trends over time
   - A filterable data table
   - A summary statistics panel
3. Implement filtering by date range and category
4. Handle loading and error states appropriately
5. Make the dashboard responsive
6. Implement data caching using localStorage

## Evaluation Criteria

### Task A:
- Identification of performance bottlenecks
- Understanding of React optimization techniques
- Quality of proposed solutions
- Justification for architectural changes

### Task B:
- Component architecture
- State management approach
- Data fetching and error handling
- UI/UX implementation
- Performance considerations
- Code quality and organization

## Submission

- Complete your work in the provided files
- Submit all files as a zip archive
- Include any additional notes or assumptions in a separate file if needed

Good luck!
